# Exp Results Meta Protocol (.npy)

This document defines the `.npy` metadata protocol saved alongside figures.

- Output root: `reports/exp_results_meta/...`
- Purpose: store figure-aligned series for cross-platform replay/reproduction.
- Writer: `utils.persist.save_npy_payload`
- Reader: `utils.load_meta.load_npy_meta` / `utils.load_meta.meta_to_dataframe`

## Directory Mapping

The folder structure mirrors `reports/figures`:

- `reports/exp_results_meta/<family>/<interval>/<run_id>/<symbol>/...`
- `reports/exp_results_meta/whitebox_only/<symbol>/...`

Typical files:

- `exp1_whitebox_forecast_<MARKET_KEY>.npy`
- `exp1_blackbox_forecast_<MARKET_KEY>.npy`
- `exp1_*_return_target_test_<MARKET_KEY>.npy`
- `exp2_<branch>_<case>_<MARKET_KEY>.npy`
- `exp2_buy_and_hold_<MARKET_KEY>.npy`

## Common Rules

- `.npy` content is a pickled Python `dict` (`allow_pickle=True`).
- Time fields use key suffix `_ts_ns`.
- `_ts_ns` values are saved as `int64` nanoseconds (UTC-compatible).
- Non-time series are `numpy` arrays or scalar values.

## Payload Kinds

### 1) `forecast_layer`

Generated by `plot_forecast_layer`.

Keys:

- `kind`: `"forecast_layer"`
- `title`: figure title
- `decision_ts_ns`: source decision timestamps (`t`)
- `target_ts_ns`: target timestamps (`t+1`) used as x-axis
- `close_gt_t1`: GT close on target axis
- `pred_price_t1`: predicted price on target axis
- `band_lo_t1`: lower band on target axis (empty if no band)
- `band_hi_t1`: upper band on target axis (empty if no band)

### 2) `return_target_layer`

Generated by `plot_return_target_layer`.

Keys:

- `kind`: `"return_target_layer"`
- `title`: figure title
- `target_ts_ns`: target timestamps (`t+1`) used as x-axis
- `pred_next_return`: predicted next return
- `real_next_return`: realized next return
- `band_lo`: lower return band (empty if no band)
- `band_hi`: upper return band (empty if no band)
- `scatter_pred`: x-values used in scatter panel
- `scatter_real`: y-values used in scatter panel

### 3) `backtest_layer`

Generated by `plot_backtest_layer`.

Keys:

- `kind`: `"backtest_layer"`
- `title`: figure title
- `close_ts_ns`: full close timeline
- `close`: close price values
- `settle_ts_ns`: settlement timeline (backtest output index)
- `decision_ts_ns`: decision timeline
- `pos`: position series on settlement rows
- `dpos`: position change series
- `pnl`: per-step pnl
- `equity_settle`: equity values on settlement rows
- `equity_ts_ns`: equity line x-axis (includes prepended start point if applicable)
- `equity_line`: equity line values
- `buy_hold_line`: normalized buy-and-hold values
- `open_long_ts_ns`: markers
- `open_short_ts_ns`: markers
- `close_short_ts_ns`: markers
- `close_long_ts_ns`: markers

## Load Example

```python
from utils.load_meta import load_npy_meta, meta_to_dataframe

meta = load_npy_meta(
    "reports/exp_results_meta/ft/1d/pretrained_native_1/btcusdt/exp1_blackbox_forecast_BTCUSDT_1d.npy"
)
df = meta_to_dataframe(meta)
print(meta["kind"])
print(df.head())
```

CLI preview:

```powershell
env\Scripts\python utils\load_meta.py reports\exp_results_meta\ft\1d\pretrained_native_1\btcusdt\exp1_blackbox_forecast_BTCUSDT_1d.npy --head 5
```

## Versioning Note

If new keys are added in future versions, keep backward compatibility by:

- preserving existing key names/semantics
- appending new keys rather than renaming old ones
